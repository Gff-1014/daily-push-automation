# 四级备考推送系统 · 项目大纲（v2 整理版 · 已落地）

> 目标：备考 2026 年 12 月英语四级（CET-4，笔试已官宣 **12 月 12 日 9:00–11:20**），
> 按考试日倒排推送四级大纲词 + 基础词，每天 08:00 与 18:00 各推送一次；
> 每次包含：新学单词、回忆单词、四级难度新闻短文（生词横线标注 + 长难句波浪线 + 长难句分析）、
> 中文翻译、听力训练（摘选 30–45 秒 · 1.25x / 1x / 0.75x 三份变速音频）+ 汉译英一句（答案空行分隔）。

## 六、阅读 / 听力 / 汉译英内容源

### 阅读（复用六级已验证 RSS 源）

| 来源 | 题材 |
| --- | --- |
| NPR Science/Tech、ScienceDaily（早间轮换） | 科技 / 社会 |
| CGTN、China Daily（晚间轮换） | 时事 |

- 抓取正文 → LLM 改写为四级难度（120–220 词）+ 中文翻译 + 1–2 句长难句分析；
- 兜底：RSS 摘要改写 / 内置示例文章。

### 听力（国内可达，已实测）

| 来源 | 说明 |
| --- | --- |
| tingroom.com VOA 慢速英语镜像 | 文章页含英文原文；`play.php?id=` 提供 mp3 直链（sound2.yywz123.com，实测可达） |

- 早晚各取一篇；英文原文随音频一起给出，中文翻译由 LLM 生成并作为答案空行放置；
- **三份变速音频**：摘选 30–45 秒（按日期在区间内确定性变化），用 ffmpeg atempo 生成
  **1.25x / 1x / 0.75x 三份 mp3**（保音调变速）并上传 COS（public-read）；
- **听力对照页**：每天生成 `index.html` 上传 COS，内嵌 `<audio>`（src 直写标签 + 失败自动切换备选）、
  三档倍速按钮、英文原文 → 空行 → 中文翻译、下载链接；处理失败才回退直链；
  本地用 imageio-ffmpeg，云函数捆绑 Linux 静态 ffmpeg（`FFMPEG_BIN`）。

### 汉译英

- LLM 用当日新词（取前 3 个）生成一句中文题目，输出参考译文 + 用词提示；
- 早间 / 晚间各一句。

## 八、技术方案（四级完全自包含，不碰六级/新闻任何文件）

| 环节 | 方案 |
| --- | --- |
| 词库 | `scripts/build_cet4.py`：SCOPE 已填（基础补强版），产出 5115 词 words.json |
| 引擎 | `src/cet4/` 独立模块：config / words / srs / state / plan / reading / listening / cne / render / notifier / main |
| 自包含依赖 | `src/cet4/fetch.py`、`src/cet4/llm.py`、`src/cet4/cos_client.py` 均为复刻副本，不再引用新闻项目共享模块 |
| 配置 | `config/cet4.yaml`（独立）+ `config/cet4.test.yaml`（测试专用状态） |
| 三份音频 + 对照页 | `src/cet4/audio.py`：ffmpeg 摘选 30–45 秒 + atempo 三份上传 COS，并生成内嵌播放器对照页（src 直写 + 失败切换） |
| ffmpeg | 本地 `imageio-ffmpeg`；云函数捆绑 Linux 静态 ffmpeg（`bin/ffmpeg` + `FFMPEG_BIN=/var/user/bin/ffmpeg`），部署包走 COS 上传避免体积限制 |
| 邮件 | `src/cet4/notifier.py`，SMTP/webhook，失败重试 3 次、连续 3 次告警暂停 |
| 部署 | `deploy/deploy_cet4.py` + `deploy_cet4.ps1`：独立函数 `cet4_push` + 08:00/18:00 触发器 + 播放页上传 |
| 状态 | `data/cet4/state.json` + COS key `cet4/state.json`，与六级完全隔离 |
